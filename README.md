<h1 align="center">🎓 Sentra</h1>

<h2>Introduction</h2>
<i>Smart and Efficient School Event Management Platform.</i>

<br>

<p align="justify">
Sentra is a school event management application developed to simplify the process of organizing, managing, and participating in school events. The platform provides an integrated system that helps schools manage event activities more efficiently, from event creation to participant monitoring.

Designed with dedicated access for administrators and students, Sentra streamlines communication and improves event coordination within the school environment. Administrators are able to manage event data, monitor participant registrations, and update event statuses in real time, while students can easily register for events and stay informed about event progress through a user-friendly interface.

By combining simplicity, functionality, and accessibility, Sentra aims to support schools in creating a more organized and effective event management experience.
</p>

---

<h2>🚀 Features</h2>

<h3>🛠️ Admin Features</h3>

- 📅 Create and manage school events efficiently.<br>
- ✏️ Update event statuses such as Upcoming, Ongoing, or Completed.<br>
- 👥 View participant details and monitor total registrations.<br>
- 🗑️ Remove inactive or completed events from the system.<br>
- 📊 Access centralized event management through an integrated dashboard.<br>

<h3>🎓 Student Features</h3>

- 📝 Register for available school events directly through the platform.<br>
- 👀 Access detailed event information and schedules.<br>
- 📢 Monitor event status updates in real time.<br>
- ⚡ Experience a simple and accessible event registration process.<br>

<h2>📌 Installation</h2>

<h3>1. 📥 Clone the Repository</h3>

```bash
git clone https://github.com/your-username/sentra.git
```

<h3>2. 📁 Navigate to the Project Folder</h3>

```bash
cd sentra
```

<h3>3. 📤 Move Project to Laragon's www Directory</h3>

```bash
C:\laragon\www\
```

<h3>4. ▶️ Start Laragon Services</h3>

<h4>
1. Apache 🟩 <br>
2. MySQL 🟦
</h4>

<h3>5. 📊 Import the Database</h3>

<h4>
1. Open phpMyAdmin <br>
2. Create a new database named: <br>
<b>sentra_db</b> <br>
3. Import the provided SQL file into the database
</h4>

<h2>🚀 Usage</h2>

<h3>

1. 🔗 Access the Application

```bash
http://localhost/sentra
```

2. 👤 Log In

* Administrators can manage school events and participant data.<br>
* Students can register for events and monitor event updates.<br>

3. 📅 Event Management (Admin)

* Create and update event information.<br>
* Monitor participant registrations.<br>
* Manage event statuses and remove inactive events.<br>

4. 📝 Event Registration (Student)

* Browse available events.<br>
* Register directly through the application.<br>
* View updated event statuses in real time.<br>

5. 📊 Monitoring and Reporting

* Administrators can review participant totals for each event.<br>
* Students can stay informed about ongoing and upcoming activities.<br>
